Privacy Policy: rclone Drive Backup

This setup is for the owner’s personal use. It uses Google Drive access to upload selected files from an external drive through a Mac and inspect file and folder information needed to manage the backup.

Backup content is stored in the owner’s Google Drive account. Credentials and authorization tokens are kept separately from this public website and its repository. Neither backup content nor credentials will be published here.

Google user data is used only for the personal backup. It is not sold, used for advertising, or provided for AI model training.

The owner controls retention and can delete backup files through Google Drive. Access can be revoked through the Google Account’s third-party connections settings. Revoking access does not itself delete existing backups.

Use of information received from Google APIs will comply with the Google API Services User Data Policy, including its Limited Use requirements.
